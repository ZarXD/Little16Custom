Semua gestur iPhone X, satu tweak

Hashil fitur tanpa perlu ganti iPhone. Tiap modul bisa dimatikan dari Settings.

🏠

Swipe-up Home

Ganti tombol home — swipe dari bawah untuk balik ke home screen.

🔄

App Switcher

Swipe-up lalu tahan, atau swipe dari dua sisi untuk membuka switcher.

🎛️

Control Center

Kenali gesture control center ala iPhone X langsung dari corner / swipe.

🖥️

Dock iPad / Floating

Dock ala iPad dengan recents mengambang di samping — jumlah ikon bisa diatur.

⬜

Rounded Dock

Ikon recent di dock dibuat mungil & radius, radius game slider untuk menyesuaikan.

📚

Rounded App Switcher

Thumbnail switcher dibikin kotak membulat ala iPad.

📶

Status bar iPhone X

Tampilan split: jam di kiri, sinyal & WiFi di kanan — tanpa ngubah resolusi, tanpa red bar.

⚙️

Settings lengkap

Semua fitur di-toggle dari Settings > Little16, tersimpan langsung.

🚫
Tanpa ganti resolusi

Status bar iPhone X dibikin lewat layout ulang view — bukan nge-ubah ukuran layar.

Cara install

Dibutuhkan jailbreak roothide (Dopamine2) untuk file arm64e, atau rootless (Dopamine).

1

Tambah repo di Sileo

Buka Sileo > Sources > Add, lalu paste:

zarxd.github.io/Little16Custom

2

Install paket Little16

Klik Little16 di repo, lalu Install. Tweak aktif otomatis setelah respring.

3

Atur di Settings

Buka Settings > Little16 dan nyalakan fitur yang kamu mau — tiap perubahan langsung tersimpan.

Pakai Sileo? Klik tombol di bawah untuk nambah repo — link-nya:
sileo://source/https://zarxd.github.io/Little16Custom
